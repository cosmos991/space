# ASTERION — 자유 함장 시뮬레이션

단일 항성계에서 함교 HUD로 항해·탐사·교역·세력 통신·전초기지 운영을 진행하는 한국어 웹 게임입니다. 전투나 직접 조종 대신 목적지와 명령을 선택하는 지휘형 프로토타입입니다.

## 실행

Node.js 22 이상. 외부 패키지 설치가 필요 없습니다.

```sh
npm run dev
# http://localhost:3000
```

```sh
npm test
npm run build
```

## 첫 항해

1. 통신 탭에서 항성 연합의 보급 계약을 수락합니다.
2. 지도에서 테라 노바를 선택하고 출항합니다. 초기 식량 5t으로 첫 계약을 수행할 수 있습니다.
3. 1×/4×/12×로 시간을 진행합니다. 도착하면 자동으로 멈춥니다.
4. 통신 탭에서 화물을 전달하고 650 CR을 받습니다.
5. 항구에서 연료를 보급하고 다른 구역을 탐사하거나 교역합니다.
6. 케플러 소행성대를 탐사하고 2,000 CR으로 전초기지를 건설하면 시간당 9 CR을 받습니다.

항성 관측 궤도를 포함한 총 8개 목적지, 항구별 가격, 40t 화물 제한, 탐사별 보상, 반복 보급 계약, 긴급 구조 사건을 제공합니다. 구역 탐사는 3회까지 가능합니다. 외곽에서 연료가 떨어지면 긴급 예인으로 복귀할 수 있습니다. 자금이 없어도 예인되므로 진행이 막히지 않습니다.

## AI 통신 설정

키 없이도 규칙 기반 로컬 통신과 모든 게임 기능을 이용할 수 있습니다. 실제 AI 통신은 서버에서 OpenAI Responses API를 호출합니다. AI는 인물 대화와 안내를 담당하며 자산·계약·항로를 직접 변경하지 않습니다. 실행 가능한 계약은 HUD 버튼으로 확정합니다.

`.env.example`을 `.env`로 복사하고 아래 서버 환경 변수를 설정하세요. `.env`는 커밋하지 않습니다.

| 변수 | 용도 |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI API 키. 브라우저에 전달하지 않습니다. |
| `OPENAI_MODEL` | 사용 가능한 모델 ID. 기본 `gpt-4.1-mini`. |
| `GAME_ACCESS_CODE` | 개인 AI 호출용 긴 임의 접근 코드. 키와 함께 설정해야 AI가 활성화됩니다. |

통신 패널의 **AI 통신 접근 코드**에 서버와 같은 코드를 입력합니다. 코드는 탭 세션에만 저장합니다. 대화는 최근 10개 메시지와 현재 게임 상태를 전송하며 API 요청은 자동 재시도하지 않습니다. 로컬 기본 제한은 IP당 분당 12회이며 서버리스 인스턴스 사이에는 공유되지 않습니다. 여러 사용자에게 AI 호출을 공개하려면 별도 계정 인증·공유 사용량 제한을 추가해야 합니다.

## Vercel

이 저장소를 Vercel에 연결하고 Framework Preset은 **Other**로 선택하세요. `vercel.json`에 빌드 명령과 출력 폴더가 설정되어 있습니다. `api/comms.js`는 서버 함수로 실행됩니다. AI를 사용할 경우 위 환경 변수를 프로젝트에 설정하고 다시 배포하세요. 별도 상시 서버는 필요 없습니다.

정적 호스팅만으로는 AI 통신 API가 실행되지 않습니다. 로컬에서는 반드시 `npm run dev` 서버를 이용하세요.

## 구조와 저장

- `engine.js`: 게임 상태와 규칙. AI와 독립적으로 동작합니다.
- `app.js` / `style.css` / `index.html`: 반응형 함교 HUD와 지도.
- `api/comms.js`: 입력 검증, 접근 코드 검증, AI/로컬 통신.
- `server.js`: 의존성 없는 개발 서버.
- `tests/`: 거래·항해·사건·계약·저장·통신 검증.

진행은 브라우저 localStorage에 자동 저장됩니다. 서버나 계정에 저장되지 않으며 다른 기기로 동기화하지 않습니다. 화면을 숨기거나 닫으면 시간이 정지합니다. 새 항해는 확인 후 현재 저장을 초기화합니다. 일반 글꼴은 오프라인 대체 글꼴로도 동작합니다.

현재 지원 범위는 개인 함선 1척, 채굴 전초기지, 조건부 행성 소유권, 주요 팩션별 신뢰와 명예입니다. 세부 행성 통치 정책, 함대, 전투, 승무원 고용, 자유 대화의 동적 계약 변환은 이후 확장 영역입니다.


## 거래소 확장

- 광물·식량·기술 부품을 1~40t 단위로 주문합니다. 1t/5t/10t/최대 수량 바로가기를 제공합니다.
- 항구별 유한 재고와 시세가 있습니다. 매수는 재고를 줄이고 가격을 올리며, 매도는 재고를 늘리고 가격을 낮춥니다. 전체 주문을 1t씩 계산하므로 대량 주문에도 가격 영향이 포함됩니다.
- 재고는 게임 시간 24시간마다 정상 수준을 향해 회복합니다. 시세는 날짜별로도 변합니다. 현실 시간이나 오프라인 시간은 반영하지 않습니다.
- 주문 금액·평균 체결가·매도 손익을 확인한 뒤 확정합니다. 시세가 바뀌면 주문을 갱신하고 다시 확인하도록 합니다.
- 화물의 가중 평균 매입 원가, 누적 교역 실현 손익, 거래 내역 60건을 저장합니다. 초기 화물과 탐사 회수품은 원가 0으로 처리합니다. 계약/구조에 쓴 화물은 원가도 제거하고 교역 손익에는 포함하지 않습니다.
- 5t 기준 교역 항로를 추천하고, 현재 편도 연료비를 차감한 예상 순익을 보여줍니다. 도착 시세 변동·귀환 비용·시간 기회비용은 별도입니다. 현재 자금·화물칸·재고로 살 수 있는 상품만 제안합니다.
- 항구별 원격 시세, 거래 내역, 화물 명세를 펼쳐 볼 수 있습니다. 원격 주문은 허용하지 않습니다.
- 기존 v1 저장을 그대로 불러오며, 기존 화물의 이전 매입 이력은 없으므로 원가 0에서 새 장부를 시작합니다.
- `economy.js`: 시장 계산과 원가/거래 장부. `trading-ui.js`: 거래소 HUD.

## 함교 화면과 독립 패널

기본 화면에는 항성계 지도, 작은 자원 표시, 현재 항로와 시간 조절만 표시합니다. 왼쪽 메뉴에서 거래소·자산·통신·함선·일지를 선택하면 전용 패널이 열립니다. 지도에서 목적지를 고르면 항법 패널이 열립니다. 패널 안의 메뉴로 다른 시스템으로 전환할 수 있습니다.

패널을 열면 시간이 정지하며 닫기·ESC·패널 바깥 클릭·하단의 돌아가기로 지도로 복귀합니다. 패널을 닫아도 시간이 자동 재개되지는 않습니다. 항법 패널에서 출항하면 패널이 닫히고 항해가 시작됩니다. 중요한 구조 사건은 대응 패널을 엽니다. 거래는 거래소 패널 안에서 수량과 금액을 확인한 후 실행합니다.

## 자동 배포

GitHub `main`과 Vercel 프로젝트가 연결되어 있으며 커밋하면 자동 배포됩니다. `vercel.json`의 배포 빌드 명령은 `npm test && npm run build`입니다. 테스트 실패 시 배포가 실패하고 기존 성공 버전이 유지됩니다. 작업 완료는 해당 커밋의 Vercel 성공 상태까지 확인합니다.

운영 주소: https://space-gamma-wheat.vercel.app

## 함선 이미지와 API 사용량

CSV 노마드의 생성형 함선 아트를 `assets/nomad.jpg`로 제공합니다. 함선 패널의 대표 이미지와 자산 카드에서 볼 수 있습니다. 원본은 1536×1024이며 웹 전송용 JPEG로 압축했습니다.

왼쪽 **API** 메뉴는 오늘(KST)·누적 요청 수, 응답 API가 반환한 입력·출력·캐시·추론 토큰, 실패 요청, 평균 응답 시간, 모델별 사용량과 최근 100건을 보여줍니다. 캐시 토큰은 입력에, 추론 토큰은 출력에 포함되므로 중복 합산하지 않습니다. 로컬 규칙 응답은 AI 토큰을 사용하지 않습니다.

사용량은 업데이트 이후 이 브라우저에서 보낸 게임 통신만 집계합니다. 별도의 localStorage 키에 저장하여 새 항해로 게임을 초기화해도 유지됩니다. 다른 기기나 앱의 요청, 이 함선 이미지 생성, 계정 잔액·실제 청구액은 집계하지 않습니다. HTTP 오류·타임아웃 등으로 usage를 받지 못하면 토큰을 0으로 추정하지 않고 미확인으로 기록합니다. 표시할 답변이 없는 경우에도 API가 usage를 반환했다면 해당 토큰을 기록합니다.

누적 합계와 모델 합계는 유지하며, 일별 합계는 최근 90일, 개별 내역은 100건을 보관합니다. 일별 모델 합계도 개별 내역 보관 수와 독립적으로 유지합니다. 대화 본문·API 키·접근 코드는 사용량 장부에 저장하지 않습니다. 여러 탭의 동시 쓰기에 대한 트랜잭션 저장소는 아니며, 서버·계정 단위 정산은 연결된 OpenAI 사용량 대시보드에서 확인하세요.

`usage.js`는 서버 응답 usage 정규화, 브라우저 집계와 사용량 패널을 담당합니다. 서버 응답은 공개 가능한 설정 모델과 토큰 수만 전달하며 API 키를 반환하지 않습니다.


## 조건부 랜덤 사건

기존 30시간 고정 구조 요청을 시간·위치·상태 기반 사건으로 교체했습니다. 판정은 UI 프레임이 아닌 게임 시간의 경계에서 진행합니다. 저장에 난수 상태를 함께 보관하므로 배속·화면 갱신·저장 후 재접속으로 결과를 다시 뽑지 않습니다.

| 규칙 | 초기 설정 |
| --- | --- |
| 시간 판정 간격 | 게임 시간 6시간 |
| 항해 기본 사건 확률 | 판정당 28% |
| 케플러·에코·장막으로 향하는 항로 | +15%p |
| 선체 50 미만 | +8%p |
| 사건 사이 최소 간격 | 12시간 |
| 동일 유형 재발 제한 | 36시간 |
| 외곽 탐사 추가 발견 | 탐사 완료 시 35%, 대기 시간 적용 |
| 항구 정박 | 강제 선택 없음. 판정당 10%로 현지 재고 감소 및 시장 보고 |
| 공개 방송 | 게임 시간 3~5시간 간격, API 호출 없음 |

사건 7종은 구조 요청, 잔해 구름, 이온 폭풍, 이동 상인, 순찰선 검문, 보급 컨테이너, 유적 신호입니다. 이온 폭풍은 외곽 항로, 순찰선은 일반 항로, 유적 신호는 에코·장막 탐사에 등장합니다. 사건은 가중치로 고르며 조건·대기 시간 때문에 실제 발생 빈도는 위 단일 판정 확률보다 낮습니다.

선택지에 비용·보상·항해 지연·손상 확률을 표시하고, 부족한 자원과 화물 공간을 사전에 검사합니다. 자원 부족 시에도 이탈·중계·안전 관측 등 진행 가능한 선택이 남습니다. 위험 선택의 결과는 버튼 확정 때 판정하며 한 번만 적용됩니다. 현재 게임에는 함선 파괴 후 진행이 없어 사건 피해로 선체가 1 미만으로 내려가지 않습니다. 이동 상인에게 매입한 화물 원가는 교역 장부의 평균 원가에 반영되며 해당 거래 자체는 사건 일지에 남습니다.

실행 중 사건이 있으면 시간·항해·수익·공개 방송이 정지합니다. 게임 내 로그 메뉴에서 판정 규칙과 누적 판정·해결 수를 확인할 수 있습니다.

## 통신 네트워크

통신 패널은 채널 목록과 메시지 피드로 구성됩니다. 기본 채널은 항성계 전체, 항성 연합, 헬리오스, 자유 항해 연맹입니다.

- **항성계 전체**: NPC 일상 방송, 실제 도착·탐사·사건·시장 보고가 올라오는 공개 피드. 실제 다른 플레이어의 채팅이 아닙니다.
- **공개 주파수 구독**: 교역 네트워크, 항로 안전망, 탐사자 라운지를 + 버튼으로 추가합니다.
- **사용자 채널**: 이름과 방송 주제를 지정하거나, 기존 세력에 연결하는 별도의 AI 대화 채널을 만듭니다. 최대 12개입니다.
- **방송 수신**: 공개 채널의 ▶ 버튼으로 1× 게임 시간을 진행해 새 방송을 받습니다. 정지 시 피드도 정지하며, 중요한 사건 발생 시 대응 패널로 이동합니다.
- **공개 게시**: 해당 주파수에 내 메시지를 남깁니다. NPC 피드는 규칙과 문장 템플릿으로 생성되며 AI 호출·토큰 비용이 발생하지 않습니다.
- **개별 AI 통신**: 세력 채널에서 전송할 때만 `/api/comms`를 호출합니다. 채널별 대화가 분리되며 최근 10개 사용자/AI 메시지만 전송합니다. 공개 피드 전체는 보내지 않습니다.
- **보관**: 채널별 최근 80개 메시지, 구독과 읽음 위치를 게임 저장에 보관합니다. 기존 세력 대화도 새 채널로 옮깁니다. API 사용량 장부는 별도로 유지합니다.

`events.js`는 조건·난수·선택지·결과를, `communications.js`는 채널과 방송 데이터를, `comms-ui.js`는 통신 HUD를 담당합니다.


## 현재 구역과 유형별 행동

항성계 지도 구성은 유지하고 실제 위치에 이중 광환·현재 위치 표식을 추가했습니다. 목적지 선택 표식과 구분되며 항해 중에는 이동 중인 노마드 표식으로 전환합니다. 현재 위치 또는 상단의 **현재 구역 행동**을 누르면 현지 패널이 열립니다. 다른 목적지를 누르면 행동 미리보기와 출항 버튼을 표시하며, 현지 서비스는 도착해야 실행할 수 있습니다. 도착하면 구역 행동 패널이 열리고 시간이 정지합니다.

| 구역 종류 | 현지 행동 |
| --- | --- |
| 정거장 | 거래, 보급, 수리, 관할 팩션 연락. 시설 구매·구역 탐사 불가 |
| 거주 행성 | 궤도·지표 조사, 현지 시장, 보급·수리, 행정청 소유권 심사 |
| 항성 | 안전 관측 궤도에서 스펙트럼 관측. 착륙·교역·소유권 매입 불가 |
| 소행성대 | 광맥 탐사, 채굴 전초기지 건설 |
| 유적 | 고대 구조물 조사, 기술 부품 회수 |
| 성운 | 센서·신호 탐사 |

조사는 구역당 3회이며 첫 조사에 명예 +8과 해당 팩션 신뢰 +2(미지정 구역은 자유 연맹)를 받습니다. 이후 단계는 기존 탐사 자원 보상을 유지하고 최초 발견 명예를 반복 지급하지 않습니다. 탐사 진행도는 조사 가능한 5개 구역을 기준으로 표시합니다. 이전 저장의 정거장 조사 기록은 삭제하지 않습니다.

## 행성 매입과 주요 팩션

테라 노바 소유권은 **10억 CR, 성계 명예 10,000, 항성 연합 신뢰 60**을 모두 충족하고 현지에서 사건 없이 대기 중일 때 매입할 수 있습니다. 조건을 확인한 뒤 별도 매입 확정을 거칩니다. 자금만 차감하며 명예·신뢰는 소비하지 않습니다. 소유권과 기본 세수 **5,000 CR/h**가 자산에 반영됩니다. 세부 행정 정책은 아직 없습니다. 모든 정거장은 자금과 명예에 관계없이 구매가 불가능하며 엔진과 저장 검증에서도 이를 차단합니다.

| 주요 팩션 | 관할과 성향 | 신뢰·명예를 얻는 행동 |
| --- | --- | --- |
| 항성 연합 | 헤이븐·테라 노바, 행정과 민간인 안전 | 보급 계약 명예 +10/신뢰 +3, 물자 구조 명예 +15/신뢰 +2, 구조 중계 명예 +3/신뢰 +1 |
| 헬리오스 기업 | 조선소, 산업과 계약 이행 | 현지 광물 10t 조달 납품: 600 CR, 명예 +8/신뢰 +4 |
| 자유 항해 연맹 | 프리포트·케플러, 자치와 독립 탐사 | 프리포트에서 새 조사 단계 공유: 단계당 명예 +5/신뢰 +2. 같은 단계 중복 불가 |

팩션 패널에 조직 소개, 목표, 선호 행동, 관할, 다른 팩션과의 관계, 현재 신뢰와 연락관을 제공합니다. 세 팩션의 신뢰는 −100~100에서 따로 저장됩니다. 명예는 공통의 누적 공적입니다. 구조 지원은 자유 연맹 신뢰도 +1 올립니다. 팩션 간 관계 설명은 현재 세계관이며 자동 전쟁이나 영토 변화는 실행하지 않습니다.

기존 저장은 완료 계약과 과거 최초 조사에서 확인할 수 있는 공적을 복원하며 이전 자금·화물·채널·API 사용량을 유지합니다. `world-data.js`가 장소와 현지 행동을, `factions.js`가 팩션 설정·공적을, `map-ui.js`·`location-ui.js`·`faction-ui.js`가 해당 화면을 담당합니다.
